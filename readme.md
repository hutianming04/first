# 步兵框架代码

## 变量 

- 大部分变量定义在`All_init.c`
- 需要使用变量时，在定义函数时将变量作为参数传入如
```c
    RobotTask(1, &WHW_V_DBUS, &RUI_V_CONTAL, &User_data,
            &CAPDATE, &VisionRxData, &RUI_ROOT_STATUS);
```

不能在函数定义内部直接引用

- RUI_V_CONTAL结构体用来存储控制相关的变量以及控制过程所需中间变量如pitch轴限幅、yaw初始角度、单发旋转角度等
- 所有电机结构体存储在一个变量`ALL_MOTOR`中

## 初始化

- 所有外设初始化打包在`Everying_Init();`函数，控制变量初始化整合在freertos任务中
- App层云台，底盘，发射任务在运行前会先进行自检，如pid是否初始化，电机是否在线，遥控器是否在线等，有一项不成功便会提前结束任务，电机在线检测函数在`RUI_ROOT_INIT.c`中，存储在线状态的变量打包在结构体`RUI_ROOT_STATUS`

## 运行

- 所有函数运行在`WHW_IRQN.c`中
- can发送整合在-task函数中，接收在`WHW_IRQN.c`，电机can接收地址无宏定义
- 不同任务间相互通讯在`RobotTask.c`中

## --

- pid前馈环对拨盘，摩擦轮影响尤其明显，调试时可以先给很小的数
- 调整pid参数遵循先速度后角度，先粗调后细调
- 将全部优化环节加上后pid解算可以跑通，但对响应速度有明显影响
- 调试前可以先将堵转检测函数注释，调好pid参数后再测试堵转电流
- 发射目前操作逻辑是"停火->单发->连发"
- 小陀螺不走直线（偏心转动）是因为底盘解算正负号不对，小陀螺时无法移动（发抖）可能是因为量纲转化不对
- 底盘跟随pid解算的kp是动态解算的，与旋转角大小有关
